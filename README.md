# 听课桥 / ClassBridge

Windows Chrome / Edge 上的中英课堂实时字幕与音视频精听网页。深色工作台采用左侧播放器、右侧逐句双语字幕布局。无需安装 npm 依赖。

- 独立网页：https://xiongzihan020110.github.io/-/
- 源码：https://github.com/xiongzihan020110/-

## 实时课堂

1. 打开右上角“设置”，选择中译英 / 英译中、在线 / 离线翻译。
2. 本地识别需先“准备当前模式模型”。Whisper tiny 负责语音识别，OPUS-MT 负责离线翻译。每个翻译方向的模型分别缓存。
3. 本地分段可选最长 1.8 / 2.8 / 4 / 8 秒，遇到短暂停顿会提前提交。较短分段减少等待，也可能影响语境与识别质量。
4. 可选“极速在线 · 浏览器语音服务”，仅用于在线模式下的系统默认麦克风；临时原文持续更新，可启用节流的临时译文预览，确认后保存正式字幕。临时译文可能修正，也会增加 API 用量。此模式会把麦克风音频交给浏览器的识别服务，不是由翻译 API 负责识别，兼容性与网络可用性以实际浏览器为准。
5. 点击“开始听课”，允许音频权限。可采集现场麦克风或浏览器提供的电脑共享音频。电脑音频需在共享时勾选音频；能采集哪些应用取决于浏览器。

识别与翻译使用独立 Worker，在线翻译最多并行两个请求，不再等待当前译文结束才识别下一段。积压时会暂停收音，保留已收集的原文和已保存录音。该实现是低延迟分段字幕，**不是零延迟、可保证时延的专业同声传译**；真实延迟取决于电脑、识别引擎、网络和翻译服务。实时麦克风表现需在自己的设备测试。

## 保留录音与课堂库

- 默认开启“保留录音至本地课堂库”。以 16kHz 单声道 PCM 录音分块保存到 IndexedDB，约 115MB / 小时，不上传到仓库或服务器。
- 暂停时保存尾部数据。新课堂保留旧课堂；右上角“课堂库”可重新打开字幕及原声。
- 可以导出原始录音 WAV、双语 TXT、SRT；导入的文件以原格式导出。
- 浏览器空间不足会提示。录音尚在进行时请勿关闭 / 刷新页面；意外中断可能丢失尚未写入的最后一块音频。私密浏览、清理站点数据或浏览器自动回收存储可能导致记录丢失，请定期导出。
- 从旧网址迁移到新域名后，模型和课堂记录不会自动迁移。旧记录请先导出。

## 音视频导入与精听

右侧“＋ 导入”或空白播放器中的导入按钮，可选择 MP3 / WAV / M4A / MP4 / WebM / Ogg 等**浏览器能够解码**的音视频文件。不是所有容器和编码都兼容；不兼容时请先转换为 WAV、MP3 或含 AAC 音轨的 MP4。

原文件先保存到本机课堂库。100MB 以内且不超过 15 分钟的媒体优先在本机解码并分块处理；较大媒体或无法直接解码的可播放容器采用按播放速度的流式读取，限制解码内存占用。单个导入文件上限 1GB，也需有足够的浏览器配额。流式读取的时间戳为近似值。可取消后续处理，保留原文件和已完成字幕。

- 点击右侧任意字幕或“逐句精听”，定位到原声并高亮当前句。
- 视频可边看边听；右侧字幕随播放位置更新，底部显示当前双语字幕。
- 上一句 / 下一句、单句循环、0.65×–1.5× 变速、字幕搜索、字号调整、隐藏译文与进度拖动。
- Whisper 片段时间戳用于定位；同片段内的多句文本按长度分配时间并标记为估算。不是逐词强制对齐，起止点可能需要在播放器中微调。
- 关闭单句循环时，导入文件连续播放；现场录音按所选句的原声片段播放。

文件与本地模式的语音不离开当前设备。在线翻译仅发送识别后的文字到所选 API；极速在线麦克风模式另外会发送音频给浏览器语音服务。

## 在线翻译 API

“设置 → 在线翻译 API 设置”支持 MyMemory、DeepSeek、硅基流动、OpenAI 兼容 Chat Completions 接口 / 自建代理，以及 LibreTranslate。

每个服务可分别保存 Base URL、模型与超时。兼容接口自动补充 `/chat/completions`，LibreTranslate 自动补充 `/translate`；可填写完整接口地址。密钥只留在当前页面内存，刷新即清除，不写入 localStorage、源码、GitHub 或课堂库。“测试连接与翻译”会向当前地址发送一句示例文字，可能产生少量 API 费用。

GitHub Pages 是静态托管。浏览器直连接口需要服务商允许跨域（CORS），前端无法绕过。长期使用请自行搭建兼容代理，并把正式密钥保存在后端。MyMemory 存在免费额度限制。程序未内置任何付费密钥，需自行核实服务商账号、模型权限、费用和额度。翻译失败保留原文，不自动切换服务。

## 本地运行与部署

安装 Node.js 22 后：

```text
node server.mjs
```

访问 http://localhost:4173 。请勿双击 HTML，麦克风、模块和离线缓存需要 localhost 或 HTTPS。

`.github/workflows/pages.yml` 在 main 更新后检查语法、运行测试并发布 dist 到 GitHub Pages。首次在仓库 Settings → Pages 中选择 GitHub Actions。上线状态以 Actions 的部署结果为准。旧页面可能需要刷新以加载新离线缓存。

node scripts/check.mjs

浏览器验证使用公开示例音频、合成录音及包含示例语音的测试视频，覆盖 IndexedDB 保存、音视频导入、精听回放、课堂恢复和深色界面。没有使用用户课堂录音，也没有用真实付费密钥进行接口测试。

## 0.4：同步、字幕开关、路径与外链

- 顶栏“极速实时”直接选择浏览器流式在线识别，减少等待确认句子的时间。可显示临时原文与临时译文。本地实时识别取消时间戳预测，默认分段缩短至 1.8 秒；设置中可用“测本机实时识别速度”测试 2 秒样本的推理耗时，不包含翻译与分段等待。文件导入仍保留时间戳。字幕空档会清除上一句画面字幕。
- 本地分段会根据最近一次推理耗时适当增加窗口，减少队列持续积压；这有助于稳定，但不能消除计算延迟。本地 CPU 无法跟上讲话时，可在“设置 → 云端语音识别 API”配置兼容 `audio/transcriptions` 的完整接口地址、语音模型和密钥，再选择“云端语音 API”引擎。该服务会收到片段音频，可能产生费用，需支持 CORS；与文字翻译 API 分开配置。密钥只留在本页内存。项目不提供密钥，也未实测任何真实付费语音账号。
- 右侧字幕栏可收起、关闭，通过顶栏“打开字幕侧栏”恢复；底部“画面字幕”独立开关。关闭界面不删除字幕或停止录音。相关显示偏好会记住。
- “课堂库 → 导入 / 导出目录”可以选择导入起始目录、录音与字幕导出目录。Windows Chrome / Edge 通过 File System Access API 需要用户授权，仅可显示文件夹名称，不能获取系统绝对路径。句柄保存到当前浏览器，重新启动后可能需要重新授权；不支持该 API 时退回文件选择与浏览器下载。原录音仍先保存到 IndexedDB，再按需导出。固定目录导出有同名文件时自动加编号。
- 字幕支持导入 SRT / VTT / JSON / 本软件 TXT，并与当前媒体按时间配对。支持导出 SRT / TXT / JSON，JSON 不包含 API 密钥。导入替换前会提示，请先导出需要保留的字幕。
- 默认“连续播放”会把当前课堂的录音块组合成完整 WAV 播放，自动越过原先的分块边界；单句循环优先。也可关闭连续播放，恢复逐句片段播放。
- “粘贴链接”支持 YouTube watch / shorts / live / youtu.be，以及哔哩哔哩 BV / av 完整链接，使用官方嵌入播放器。哔站 b23.tv 短链接需先在浏览器展开；登录、地区、网络或禁止嵌入的限制可能使个别视频不能播放，应用不绕过这些限制。
- 外链音频不能直接从跨域 iframe 提取。识别流程是：载入视频 → 再打开“粘贴链接” → “共享标签页音频识别” → 选择当前听课桥标签页并勾选音频 → 播放视频。可使用本地识别或配置好的云端语音 API。此流程需要用户选择共享来源，不会自动获取平台原生字幕或下载平台视频。生成字幕以捕获录音时间为准，点击句子会切回保存的原声精听，不保证与站外播放器时间轴强制对齐。

零延迟同步不能由分段识别保证。浏览器在线识别与云端 API 的速度也受服务商、网络及浏览器影响；录入之后的本地文件及导入字幕可按保存的时间轴精听。

## 0.4.1：外链音频连接与字幕一致性修复

修复了外链样式隐藏画面字幕的问题，并将外链字幕层置于 iframe 之上；“画面字幕”开关仍有效。临时原文、临时译文、正式字幕与待翻译状态共用一份字幕状态，画面和侧栏同步显示，旧的异步翻译结果不能覆盖新句子。

载入外链后，播放器上方始终显示“连接视频音频并实时翻译”。也可以在链接窗口使用“载入并实时翻译”：它会在点击手势中请求共享，避免异步准备导致浏览器拒绝弹出共享窗口。Chrome 仍要求用户选择共享来源并勾选音频；网站不能代替用户授权。请求明确设置 restrictOwnAudio=false，避免把当前页面的声音过滤掉。

连接状态区分未连接、准备模型、已连接、收到声音、正在翻译、静音及失败。连接后 8 秒没有音量会明确提醒检查播放、静音和共享标签页；首次使用本地识别会自动准备模型，下载期间应暂停原视频。默认的“开始听课”按钮在外链模式也会连接标签页音频，麦克风极速入口不会错误地用麦克风识别视频。

回归测试包含：提供公开样本生成的真实 MediaStream，经过同一 AudioWorklet → 本地识别 → 离线翻译链路；逐帧比对画面与侧栏的原文及译文，并验证外链模式的字幕层可见。这不是对第三方视频音轨的实际屏幕共享授权测试。第三方平台是否播放和 Chrome 是否授予音频权限，仍需在真实使用环境确认。

本地开发可运行 qa=capture 测试入口，入口只对 localhost / 127.0.0.1 生效，部署到 GitHub Pages 不开放媒体流注入。测试页面保存在 tests/browser-live-caption-check.html。


### Google 官方文字翻译（v0.4.4）

在“设置 → 在线翻译 API 设置”选择“Google 翻译 · 官方 API”，填写 Google Cloud API Key 并点击“测试并使用”。地址和语言代码自动配置，无需填写模型。需在对应项目启用 Cloud Translation API 和计费；免费额度按 Google 当前规则计算。

密钥仅存于页面内存，通过 X-goog-api-key 请求头直接发送至 translation.googleapis.com。可在 Google Cloud 限制密钥仅访问 Cloud Translation API，并允许网站来源 https://xiongzihan020110.github.io/*。刷新后需重新填入密钥。该选项仅翻译文字，不会更改语音识别引擎。


### 免 Key 听课（v0.4.5）

首次更新默认选择 Chrome 内置翻译，并在支持的浏览器中选择浏览器麦克风语音识别。点击顶部“免 Key 听课”准备中英语言包，再点击“开始听课”允许麦克风。无需 API Key 或信用卡。文字由浏览器本地模型翻译；语音识别依赖浏览器语音服务，通常需联网并会上传音频。此模式只支持默认麦克风，不直接读取哔站/YouTube 音频。

语言包按方向准备，切换中英文方向后可再次点击按钮。不支持、下载失败时明确报错，不自动调用收费 API。新启动器会等当前版本的离线缓存接管后再加载程序，防止新旧模块混用。
